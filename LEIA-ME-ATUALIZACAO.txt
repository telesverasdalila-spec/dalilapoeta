======================================================================
PASSO A PASSO (Windows)
======================================================================

1) Localize o zip baixado (Chrome: Ctrl+J > "Mostrar na pasta").

2) Clique com o BOTÃO DIREITO no zip > "Extrair tudo..." > no destino
   digite exatamente a pasta do projeto no seu Desktop:

   C:\Users\Windows 10\Desktop

   (O zip já vem com a pastinha "dalila-teles-veras" dentro, então extrair
   no Desktop faz os arquivos caírem no lugar certo.)

   ATENÇÃO: se depois de extrair aparecer uma pasta "dalila-teles-veras (2)"
   no Desktop, deu errado — apague a pasta "(2)" e refaça a extração
   no Desktop, conforme o passo 2.

3) Se o Windows perguntar "Substituir ou Ignorar arquivos?":
   > Marque "Faça isso para os itens restantes" e clique em SUBSTITUIR.
   Se perguntar sobre "Mesclar" pastas: confirme MESCLAR.

4) No VS Code, se o servidor estiver rodando, ele recarrega sozinho.
   Se não estiver: terminal do VS Code (Ctrl+ç) e rode:

   npx next dev -p 3000

5) Abra http://localhost:3000 > eixo Obra > aba Resenhas:
   - Leituras Críticas e Estudos Críticas agora mostram as linhas com
     o link "Leia o texto →".

PS: se você ainda não aplicou a "Atualização rápida — 04/10/2026 (rodapé)",
pode aplicar as duas em qualquer ordem — não conflitam.
