COMO USAR A FICHA MÍDIA E CONTATO
---------------------------------
- ABRIR: Eixo Vida -> Mídia e Contato
- EDITAR um link: clique no grupo (ex.: 🔗 Sites e Redes Sociais)
  -> clique no link -> mude Nome / Endereço / Descrição -> Save
- ADICIONAR um link novo: abra o grupo -> botão "Add" na lista
  "Links do grupo" -> preencha Nome e Endereço -> Save
  (dica: pode usar emoji no nome — 🎥 YouTube, 🎵 Spotify...)
- APAGAR um link: abra o grupo -> lixeirinha à direita do link
  -> Save. APAGAR um grupo inteiro: lixeirinha ao lado do
  título do grupo -> Save
- E-MAIL: o endereço começa com "mailto:" (ex.:
  mailto:nome@exemplo.com.br) — assim vira link clicável
- A "Linha final" é opcional: se apagar o conteúdo e salvar,
  o bloco do endereço some da página
- IMPORTANTE: sempre clique em SAVE depois de qualquer mudança
