COMO APLICAR (passo a passo de sempre)
--------------------------------------
1. Descompacte este zip DENTRO da pasta do projeto
   (C:\Users\Windows 10\Desktop\dalila-teles-veras),
   por cima do que existe — confirme "Substituir"
   São 5 arquivos:
     keystatic.config.ts
     src/app/data/vida/premios.json
     src/app/components/SecaoPremios.tsx
     src/app/components/CabecalhoFixo.tsx
     worklog.md
2. No VS Code: ícone do tronquinho (Source Control)
   -> "+" em cada arquivo (ou em Changes, todos de uma vez)
   -> caixinha de Message: "painel com 3 eixos + premios dadificado"
   -> botão ✓ Commit
   -> Sync Changes
3. Aguarde a Vercel reconstruir (2-3 minutos)
4. Abra o painel em JANELA ANÔNIMA:
   https://dalila-teles-poeta.vercel.app/keystatic
   Ctrl+Shift+R para recarregar sem cache

COMO USAR A NOVA FICHA (Prêmios)
--------------------------------
- ABRIR: menu do painel -> Eixo Vida -> Prêmios e Reconhecimento
- EDITAR um prêmio: clique na linha -> mude Ano ou Texto -> Save
- ADICIONAR: botão "Add" na lista -> preencha -> Save
- APAGAR: clique na lixeirinha à direita da linha -> Save
  (pronto: o prêmio sai da lista e do site na próxima
   reconstrução — sem código, sem programador)
- IMPORTANTE: sempre clique em SAVE depois de qualquer mudança

TRANQUILIDADE (cinto de segurança)
----------------------------------
- Cada Save vira um commit no cofre (GitHub). Se algo for
  apagado sem querer, NADA se perde: o histórico guarda cada
  versão e a gente restaura — é só avisar.
- Recomendo olhar a aba "Commits" em https://keystatic.cloud
  de vez em quando: é o diário de bordo automático do cofre.
