PACOTE 12 — Script de construção para a fornalha da Hostinger
================================================================

O QUE TEM AQUI?
- package.json : ganhou um script novo chamado "build:hostinger"
  (é um comando de construção que usa o "assador sênior" webpack,
  porque o assador novo, Turbopack, engasga na fornalha da Hostinger)
- worklog.md   : diário da ourives (Task 110)

O QUE MUDA NO SITE?
- NADA para o visitante. O site na Vercel segue intocado.
- Este script só serve para o TESTE na Hostinger.

JÁ FOI TESTADO?
- SIM! O bolo inteiro foi assado com este script na bancada:
  todas as páginas, o painel /keystatic, as APIs — tudo OK.

================================================================
PASSO A PASSO (a rotina de sempre, + 2 cliques novos)
================================================================

1. Descompacte este zip na raiz do seu projeto local
   (os arquivos por cima dos antigos — é só 1 arquivo de código).

2. No VS Code:
   - clica no tronquinho (Source Control)
   - botão +
   - mensagem: "script build:hostinger para teste na Hostinger"
   - Commit e depois Sync Changes

3. No hPanel da Hostinger:
   - Websites → seu app dalilapoeta
   - Abra as configurações de compilação/deploy (a tela com o
     campo "Comando de construção")
   - No menu do campo, AGORA vai aparecer uma opção nova:
       npm run build:hostinger   ← escolha ESSA
   - Salvar e clicar Redeploy (Reimplantar)

4. Quando o build passar (barra verde), abra o endereço
   temporário do app e teste:
   - a home abre?
   - uma aba da Obra abre?
   - o painel: endereço + /keystatic  ← o teste de fogo!

5. Me traga o resultado (ou o print do log, se engasgar).

================================================================
LEMBRETES
================================================================
- Se a opção "npm run build:hostinger" NÃO aparecer no menu,
  atualize a página (F5) — o hPanel lê os scripts do cofre.
- O domínio dalilatelesveras.com.br só será apontado DEPOIS
  de o teste passar. Placa nova só com bolo assado!
- Nada aqui mexe no painel, nas fichas ou no Keystatic Cloud.
