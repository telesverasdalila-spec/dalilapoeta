O QUE ESTE PACOTE FAZ

Publicadas) e muda a publicação ponto(s) da gaveta Poesia para a nova

fundo negro).

ARQUIVOS DESTE PACOTE (4 arquivos + este bilhete)
├── src/app/components/CabecalhoObra.tsx ............. botão "Coleção Mimo" nas sub-abas
├── src/app/components/SecaoObras.tsx ................ gaveta dadosMimo + ponto(s) migrou da Poesia
├── src/app/obra/[id]/pontos/dados.json .............. gênero "Coleção Mimo" + caminho da capa nova
└── public/imagens/obras-publicadas/mimo/pontos.jpg .. capa nova (JPG, 400x600)

COMO SUBIR NO GITHUB (passo a passo para não faltar arquivo)
1. Descompacte ESTE zip no seu computador. Vão aparecer duas PASTAS
   (src e public) e este LEIA-ME.
2. No GitHub, botão "Add file" → "Upload files".
3. ARRASTE AS DUAS PASTAS (src e public) JUNTAS para a área de upload.
   O GitHub preserva automaticamente as pastinhas internas (components,
   obra, imagens...) — não precisa abrir pasta por pasta.
4. ANTES de apertar "Commit changes", confira a lista de arquivos: devem
   aparecer os 4 caminhos acima (pode rolar a lista para conferir).
5. Mensagem sugerida do commit:
   "aplica o pacote Coleção Mimo (sub-aba + ponto(s) + capa nova)"
6. DEPOIS do commit, o resumo deve dizer "5 files changed" (os 4 arquivos +
   este LEIA-ME, se você o subir junto). Se disser "1 file changed", só o
   bilhete subiu — repita o arraste das pastas e avise a gente do site.
7. Aguarde o deploy da Vercel (~2–3 min) e confira em janela anônima com
   Ctrl+Shift+R:
   - Obra → Obras Publicadas → sub-aba "Coleção Mimo" ao lado de Poesia | Prosa
   - cartão ponto(s) dentro dela; Poesia sem ponto(s)
   - ficha /obra/pontos com capa nova e gênero COLEÇÃO MIMO
