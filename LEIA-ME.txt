SALA DE COSTURA — PACOTE v3 (fecho do Keystatic Cloud)
========================================================

O que e este pacote?
--------------------
Um unico arquivo: keystatic.config.ts (atualizado).

Na Viagem 2 criamos o projeto "dalilapoeta" dentro do team "dalila"
no Keystatic Cloud. Este pacote grava o endereco real desse cofre
(project: 'dalila/dalilapoeta') no arquivo de configuracao do painel.

Tambem corrigimos a posicao do fecho: o campo "project" agora fica
num bloco proprio "cloud", exatamente como o Keystatic pede
(era a unica peca que faltava encaixar).

Como aplicar (o gesto de sempre)
--------------------------------
1. Descompacte este zip DENTRO da pasta local do site (a mesma pasta
   que contem src, package.json etc.). O Windows vai perguntar se
   quer substituir o arquivo existente — sim, substituir.
2. No GitHub Desktop:
   - Ele vai mostrar 1 arquivo alterado (keystatic.config.ts).
   - Escreva a mensagem do commit: config cloud
   - Clique em "Commit to main" e depois em "Push origin".
3. Aguarde a Vercel reconstruir (2 a 3 minutos).
4. Teste em janela anonima (Ctrl+Shift+R):
   https://dalila-teles-poeta.vercel.app/keystatic

O que vai acontecer no painel
-----------------------------
Agora, ao abrir /keystatic, o painel deve pedir login pelo
Keystatic Cloud ("Sign in with GitHub" / entrar com sua conta).
E o esperado: a Sala de Costura passou a conversar com o cofre.

Detalhe carinhoso (sem urgencia)
--------------------------------
Depois que o painel estiver logando, vale conferir que o projeto no
Keystatic Cloud tem o endereco do site preenchido ("Primary URL" =
https://dalila-teles-poeta.vercel.app) — foi o passo que fizemos
na tela de Settings do projeto.

Lembretes que continuam valendo
-------------------------------
- O site continua lendo os dados de src/app/obra/[id]/*/dados.
- Quando a autora salvar algo no painel, o Keystatic Cloud registra
  a mudanca no repositorio GitHub, e a Vercel reconstrui o site
  automaticamente (2 a 3 minutos para aparecer).
- Chaves que estavam com texto vazio (ex.: "subtitulo": "") deixam
  de existir no JSON depois da primeira edicao pela autora. Isso e
  normal e nao afeta o site.
