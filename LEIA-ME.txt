PACOTE 13 — Fontes costuradas no cofre (à prova de fornalha)
================================================================

O QUE TEM AQUI?
- src/app/layout.tsx ........... troca a busca de fontes na internet
                                  por fontes locais (next/font/local)
- src/app/fonts/inter-var.woff2 ...... fonte Inter (oficial Google Fonts)
- src/app/fonts/cormorant-var.woff2 .. fonte Cormorant Garamond (oficial)
- worklog.md / LEIA-ME.txt ..... diário e bilhete

POR QUÊ?
- O build novo (webpack) já passou pelo CSS, mas morreu na porta
  seguinte: o site pedia as fontes AO GOOGLE, pela internet, a cada
  build — e a fornalha da Hostinger não alcança essa porta.
- Agora as fontes moram DENTRO do cofre: nenhum build depende
  mais de internet. Na Vercel, só fica mais robusto também.

O QUE MUDA NO SITE?
- NADA para o olho: são os mesmos arquivos oficiais do Google
  Fonts, mesmos pesos, mesmas variáveis de cor/tipografia.

JÁ FOI TESTADO?
- SIM! Bolo inteiro assado na bancada com este código: todas as
  páginas, o painel /keystatic, as APIs — tudo OK.

================================================================
PASSO A PASSO
================================================================

1. Descompacte este zip na raiz do seu projeto local
   (mantém as pastas: src/app/... — os arquivos entram no lugar).

2. No VS Code:
   - tronquinho → + → mensagem:
     "fontes locais para build na Hostinger"
   - Commit → Sync Changes

3. NÃO PRECISA MEXER NA HOSTINGER! O redeploy dispara sozinho
   quando o sync sobe (o app já está com build:hostinger).
   Só espie a aba Implantações e veja a barra de build andar.

4. Quando ficar verde, abra o endereço temporário e teste:
   - a home abre com as letras bonitas?
   - uma aba da Obra abre?
   - o painel: endereço + /keystatic  ← o teste de fogo!

5. Me traga o resultado (ou print do log, se engasgar).
