COMO USAR AS FICHAS DO MOVIMENTO
--------------------------------
- ABRIR: menu -> Movimento · Ativismo Cultural -> escolha a gaveta
- CADA REGISTRO aparece na lista como "Título (ano)" — ex.:
  "Sarau Poesia sem Quartel! (2016)"
- EDITAR: clique no registro -> mude o campo -> Save
- ADICIONAR evento novo: botão "Add" na lista "Registros (eventos)"
  -> preencha Título, Data (AAAA-MM-DD), Local... -> Save
- APAGAR: lixeirinha à direita do registro -> Save
  (a lixeirinha também funciona na gaveta inteira, se um dia
   precisar esvaziar uma categoria — mas recomendo NÃO apagar
   gavetas: elas são a estrutura do site)

AS TAGS (o que você pediu!)
---------------------------
- Cada evento tem a lista "Tags do evento" — são LIVRES:
  clique em Add e digite qualquer tag (sarau, palestra, oficina,
  residência, lançamento... o que quiser!)
- A cor de cada tag vem do mapa de cores do site; tags novas
  ganham a cor padrão. Se um dia quiser uma COR batizada para
  uma tag nova, é só me pedir (mudança de código, 5 minutos)
- "Tags comuns" no topo da ficha é só um lembrete informativo

CAMPINHOS COM "(não mexer)"
---------------------------
- ID único, Número de ordem, Categoria interna/principal,
  Total de registros e Slug do texto: são engrenagens internas.
  Pode olhar, mas não recomendo alterar — em caso de dúvida,
  me chame antes de salvar.
